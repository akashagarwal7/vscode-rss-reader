# Changelog

## 0.1.0

- Feed tree in the activity bar with unread badge and status bar count.
- Global feeds (`~/.rss-feed-curator/feeds.json`) and project feeds (`.vscode/rss-feeds.json`), with JSON schema.
- RSS 2.0, RSS 1.0 (RDF), Atom and JSON Feed; feed auto-discovery from website URLs.
- Background refresh every 2 hours (configurable), coordinated across windows and editors; conditional GET.
- In-editor and macOS/Linux system notifications for new posts.
- Read/unread state persisted globally and shared between VS Code and Cursor.
